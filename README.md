# BUCOM_ (부컴)
### 부산·울산·김해·양산 컴퓨터 출장 수리 전문 서비스

![BUCOM Banner](https://images.unsplash.com/photo-1587202372775-e229f172b9d7?auto=format&fit=crop&q=80&w=1200)

**부컴(BUCOM)**은 10년 경력의 베테랑 엔지니어가 직접 운영하는 컴퓨터 전문 수리 서비스입니다. 정직한 진단, 투명한 서비스, 완벽한 기술력으로 고객님의 디지털 라이프를 책임집니다.

---

## 🚀 주요 서비스 (Key Services)

- **데스크탑 판매 및 조립**: 사무용부터 하이엔드 게이밍 PC까지 최적의 견적 제공.
- **하드웨어 수리**: 부팅 불량, 전원 고장, 블루스크린 등 모든 하드웨어 문제 해결.
- **OS 설치 및 최적화**: Windows 10/11 정품 설치 및 시스템 성능 최적화.
- **데이터 정밀 복구**: 삭제된 파일, 인식 불량 저장 장치(HDD/SSD/USB) 데이터 복원.
- **네트워크 및 보안**: 사무실 랜공사, NAS 구축, CCTV 보안 시스템 설치.
- **노트북 수리**: 액정 파손, 키보드 교체, 배터리 수리 및 내부 청소.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: React 19, Vite, Tailwind CSS, Motion (Animations), Lucide React (Icons)
- **Backend**: Express (Node.js), Google Sheets API (Data Management), Telegram Bot API (Real-time Notification)
- **Deployment**: Vercel

## 📱 실시간 문의 시스템 (Inquiry System)

고객이 웹사이트를 통해 문의를 접수하면 다음과 같은 프로세스가 즉시 실행됩니다:
1. **텔레그램 알림**: 관리자에게 즉시 수리 요청 내용이 전송됩니다.
2. **구글 시트 기록**: 모든 문의 내역이 구글 스프레드시트에 자동으로 기록되어 체계적으로 관리됩니다.
